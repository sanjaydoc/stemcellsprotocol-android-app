# StemCells Protocol — Android app

Public host for the StemCells Protocol Android APK (Capacitor build of stemcellsprotocol.com).

**Download:** [stemcells-protocol.apk](https://github.com/sanjaydoc/stemcellsprotocol-android-app/raw/main/stemcells-protocol.apk)

Sideload: enable "Install unknown apps" for your browser, open the APK, install.
Online mode uses the cloud assistant; offline (on-device) mode is in development.

_Not a medical device. Educational/research support only._
